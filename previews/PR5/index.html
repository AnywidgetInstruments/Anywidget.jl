Anywidget.jl is a community-maintained Julia host for anywidget front-end modules; it is not affiliated with the anywidget project.

Anywidget.jl hosts anywidget front-end modules (AFM) from Julia. An AFM is an ES module exporting { initialize?, render } that drives a model provided by the host (get, set, save_changes, on, off, send). This package binds such a module to a trait dictionary and hosts it.

using Anywidget

counter = FrontendModule("counter"; source = """
export default {
  render({ model, el }) {
    const b = document.createElement("button");
    const show = () => (b.textContent = `count: ${model.get("count")}`);
    b.onclick = () => { model.set("count", model.get("count") + 1); model.save_changes(); };
    model.on("change:count", show);
    show();
    el.appendChild(b);
  },
};
""")

anywidget(counter; count = 0)
